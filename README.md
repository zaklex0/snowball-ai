# Snowball.ai — исходный код

Программа для Windows на Electron. Промты хранятся в `Документы\Snowball.ai\prompts.json`, прикреплённые файлы лежат в подпапке `Файлы`.

- `main.js` — окно программы и работа с диском (сохранение, файлы, папки, импорт и экспорт). Там же переезд данных со старых названий программы (версии 1.0.0 и 1.1.0).
- `storage.js` — чтение и запись `prompts.json`, резервная копия, копирование файлов.
- `preload.js` — «мостик» между окном и диском.
- `src/` — интерфейс: `index.html`, `styles.css`, `app.js`, шрифты.

Сборка установщика (нужен Node.js):

    npm install
    npx electron-builder --win nsis --x64

Готовый установщик появится в папке `dist`. Перед сборкой новой версии увеличьте `version` в `package.json`.
