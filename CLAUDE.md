# Snowball.ai

Программа для Windows на Electron: система хранения промтов. У каждого промта есть название, тип, текст и прикреплённые файлы.
Интерфейс на русском. Владелец не программист, поэтому объясняй простыми словами и без жаргона.

## Где что лежит
- `main.js` — главный процесс: окно (на Windows своя полоска заголовка через `titleBarOverlay`), обработчики IPC, диалоги, настройки, переезд со старых названий программы (`LEGACY_TITLES`).
- `storage.js` — работа с данными: `prompts.json`, `prompts.backup.json`, папка `Файлы/<id промта>/`. Модуль не зависит от Electron, поэтому его можно проверять обычным `node`.
- `preload.js` — мост `window.vsApi` между окном и `main.js`.
- `src/` — интерфейс: `index.html`, `styles.css` (все цвета заданы CSS-переменными, есть светлая и тёмная тема), `app.js` и локальные шрифты.

## Данные пользователя
- По умолчанию данные лежат в «Документы\Snowball.ai». Папку можно сменить в меню «⋯». Настройки хранятся в `%APPDATA%\Snowball.ai\settings.json`.
- Не удаляй данные пользователя. Не меняй формат `prompts.json` так, чтобы старые файлы перестали читаться.

## Дизайн
- Тёплая пастельная палитра. Цвета типов: «Статика» — зелёный, «Видео» — синий, «Системные» — красный. Список типов задан в `CATEGORIES` в `app.js`, их цвета — в `styles.css`.
- Шрифты: Unbounded для заголовка, Golos Text для текста, IBM Plex Mono для промтов.

## Сборка
- `npm install`
- `npx electron-builder --win nsis --x64` → готовый установщик `dist\Snowball-Setup-<версия>.exe`
- Перед каждым выпуском увеличивай `version` в `package.json`.
- Не меняй `build.nsis.guid`: по нему новая версия при установке заменяет старую.

## Планы
- Автообновления через GitHub Releases: `electron-updater` и `publish` с provider `github`.
- Версия для телефона или браузера. Промты можно перенести через «Сохранить промты в файл».
