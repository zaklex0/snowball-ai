Настройки

ChatGPT

Чтобы в «Ассистенте» отвечал ChatGPT, нужен свой API-ключ OpenAI. Его создают на сайте platform.openai.com в разделе API keys. Оплата там отдельная от подписки ChatGPT Plus: деньги списываются за каждый ответ с баланса в разделе Billing.

Точный баланс на сайте
Узнать остаток по ключу сервисы не дают, поэтому программа сама считает, сколько стоили её ответы. Это примерная сумма: траты в других программах и на сайте сюда не попадают.

Claude

Чтобы отвечал Claude, нужен свой API-ключ Anthropic. Его создают на сайте console.anthropic.com в разделе API Keys. Оплата там отдельная от подписки Claude.ai.

Точный баланс на сайте
Узнать остаток по ключу сервисы не дают, поэтому программа сама считает, сколько стоили её ответы. Это примерная сумма: траты в других программах и на сайте сюда не попадают.

Ассистент

Ключи хранятся только на этом компьютере, зашифрованными средствами Windows, отдельно от папки с промтами. В файл с промтами и в другие программы они не попадают. Пока нет ни одного ключа, в «Ассистенте» отвечает заглушка. Модель и глубину размышлений выбирают кнопкой «Модель» в поле ввода.

Резервная копия

Один файл .snowball со всем, что есть в программе: промты с картинками и видео, разговоры с ассистентом, календарь, статистика, профиль и тема. Пригодится, чтобы перенести всё на другой компьютер или поставить программу заново. Ключей ChatGPT и Claude в копии нет, их вводят заново.

При восстановлении ничего не удаляется: добавляется только то, чего в программе ещё нет. Файл копии можно и просто перетащить в окно программы.
